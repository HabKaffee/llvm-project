Это лпагин для LLVM, который заменяет целочисленное умножение на побитовый сдвиг влево, если один из операндов является степенью двойки
для сборки плагина использовать:
cd llvm-project/build
ninja MultiplyOpt

для запуска тестов:
ninja check-clang-examples-MultiplyOpt

при успешном выполнение тестов будет выведено (файл с тестами один, в файле 4 теста):
PASS: MultiplyOpt :: test.ll (1 of 1)
